# Ejercicio 1

Escriba un script Python que reciba como parámetro una URL y descargue la página HTML correspondiente. Luego, extraiga de la misma los enlaces y los muestre por consola.

## Ejecucion

```bash
python TP5/EJ1/EJ1.py <URL>
```

```bash
python TP5/EJ1/EJ1.py "https://example.com"
```

```bash
python TP5/EJ1/EJ1.py "https://es.wikipedia.org/wiki/Argentina"
```
